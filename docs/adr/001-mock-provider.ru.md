# ADR-001: Mock-провайдер при отсутствии API-ключа

**[English](001-mock-provider.md)** · Русский

**Статус:** Принято  
**Дата:** 2026-07-06

## Контекст

OpenWeatherMap требует API-ключ. Демо портфолио и CI должны работать без секретов.

## Решение

Если `OPENWEATHER_API_KEY` пуст, логируем предупреждение и используем провайдер `Mock` с детерминированным выводом.

## Последствия

- Простая локальная демонстрация
- Тесты никогда не обращаются к внешнему API
- В production ключ нужно задать явно
